此项目为边缘世界模组

目前已大体完成

已完成功能：

为每个由殖民地殖民者或是机械体制作的食物添加标签。标签内容包括厨师、烹饪等级

自定义可开启：单挑仪式和平模式，空手单挑，自定义攻击、移动时间

添加食物对于社交评价的影响

为所有文化添加单挑仪式，单挑随时可进行，没有频繁开启质量减益，仅与在双方格斗技能差值（越小越精彩）和场地观感有关

仪式必要组成为：一位有负面评价的厨师，一位对此厨师有负面评价的食客。

单挑结束会根据质量提供心情和技能点数

厨师失败会短期内完全提升厨艺，使其无法做出有毒食物，食客失败则会添加心情Debuff和食物中毒，平手则双方获得心情加成

若机械体做饭引发中毒，追责会指向它的机械师，若是机械师就是食客，那他的这台机械体会获得短期厨艺增益buff
